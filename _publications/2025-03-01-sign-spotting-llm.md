We propose using Large Language Models to resolve sign spotting ambiguities. By combining visual sign spotting scores with LLM-derived language priors, we improve spotting accuracy in cases where multiple candidate glosses are visually plausible, demonstrating the value of cross-modal context for sign language understanding.
